# 不抽设计系统

## 1. 设计目标

希望用户感到平静、诚实、可控，而不是被监督或被奖励机制催促。

设计参考 [Apple Design SKILL](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md) 中的即时反馈、空间一致性、克制、系统字体和可中断动效原则，但不在 Android 上照搬 iOS 控件。

## 2. 基础原则

1. 状态先于操作：先告诉用户现在是什么状态，再提供下一步。
2. 一致性先于装饰：同一层级只能有一套字号、间距和圆角。
3. 简单不是隐藏：重要状态和后果必须明确表达。
4. 反馈与提交同步：状态、轻触反馈和视觉变化在同一次操作中发生。
5. 动效服务空间关系：页面、底部面板和卡片从合理来源出现并沿原路径返回。
6. 深色模式不是反色：重新校准表面层级、文字对比度和状态色。

## 3. 布局网格

基础单位为 4dp。业务页面只能使用以下间距 Token：

| Token | 值 | 用途 |
|---|---:|---|
| `space2` | 2dp | 图形内部微调，极少使用 |
| `space4` | 4dp | 紧密元素 |
| `space8` | 8dp | 标签与辅助文字 |
| `space12` | 12dp | 同组控件 |
| `space16` | 16dp | 卡片内部基础间距 |
| `space20` | 20dp | 页面水平边距（紧凑设备） |
| `space24` | 24dp | 区块内部大间距、宽屏页边距 |
| `space32` | 32dp | 页面区块间距 |
| `space40` | 40dp | 主层级分隔 |
| `space48` | 48dp | Hero 留白 |

页面默认水平边距 20dp；宽度达到 600dp 时内容最大宽度 560dp 并居中。所有页面处理状态栏、导航栏和键盘 Insets。

## 4. 圆角

| Token | 值 | 用途 |
|---|---:|---|
| `radiusSmall` | 10dp | 标签、小型选择项 |
| `radiusControl` | 14dp | 输入框、普通按钮 |
| `radiusCard` | 20dp | 常规卡片、设置分组 |
| `radiusHero` | 28dp | 首页主状态区域 |
| `radiusFull` | 999dp | 胶囊状态和 Tab 选中背景 |

页面不得自行引入 16dp、18dp、24dp 等近似圆角。确有新层级时先修改本文件。

## 5. 排版

使用平台系统字体，支持系统字体缩放。中文不强行设置字距；英文大标题可以轻微负字距。

| 角色 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `displayHero` | 56sp / 60sp | 600 | 首页连续天数数字 |
| `headline` | 30sp / 36sp | 600 | 一级页面标题 |
| `titleLarge` | 24sp / 30sp | 600 | 重要卡片标题 |
| `title` | 20sp / 26sp | 600 | 区块标题 |
| `bodyLarge` | 17sp / 25sp | 400 | 主要说明 |
| `body` | 15sp / 22sp | 400 | 正文和设置项 |
| `label` | 13sp / 18sp | 500 | 标签、辅助指标 |
| `tabLabel` | 12sp / 16sp | 500/600 | Tab 未选中/选中 |

数字统计使用等宽数字特性；金额、支数和百分比的单位不得与主数字争夺层级。

## 6. 色彩语义

颜色由语义命名，不允许业务页面直接引用十六进制值。

### 浅色建议值

| Token | 值 | 用途 |
|---|---|---|
| `background` | `#F6F5F1` | 暖灰背景 |
| `surface` | `#FCFBF8` | 常规表面 |
| `surfaceElevated` | `#FFFFFF` | 浮层和底部面板 |
| `textPrimary` | `#1C211E` | 主文字 |
| `textSecondary` | `#69706B` | 辅助文字 |
| `primary` | `#476455` | 主操作、选中状态 |
| `primaryContainer` | `#DEE9E2` | 柔和强调背景 |
| `smokeFree` | `#3F6B50` | 无烟状态 |
| `smoked` | `#A24C43` | 吸烟和危险操作 |
| `unrecorded` | `#929792` | 未记录状态 |
| `divider` | `#E5E2DA` | 弱分隔 |

深色方案保持相同语义，使用深灰绿色背景而不是纯黑。实现前必须验证普通文字对比度至少 4.5:1，大文字至少 3:1。

状态不能只依赖颜色，必须同时使用文字或形状。

## 7. 表面与层级

- 默认页面不使用阴影堆叠层级。
- 常规卡片使用背景差和间距区分。
- 底部面板可以使用轻量阴影和遮罩。
- Tab Bar 是固定的功能层，可使用半透明表面；设备不适合实时模糊时退化为高不透明度纯色，不牺牲性能和清晰度。
- 不用硬分隔线切割每个设置项；优先使用分组、间距和弱分隔。

## 8. 统一底部 Tab Bar

唯一实现组件：`BuchouTabBar`。

- 三个等宽项目：不抽、记录、设置。
- 每项使用 24dp 图标和一行文字。
- 内容高度 64dp，额外叠加系统导航栏底部 Insets。
- 整个项目最小触控区域 48dp。
- 选中项使用 `primaryContainer` 胶囊图标背景和加重文字。
- 未选中项使用 `textSecondary`。
- 页面内容可以滚动到 Tab Bar 下方，但必须保留安全的内容底部间距。
- 切换 Tab 使用短交叉淡入或轻微位移；动画可被连续点击打断。

任何页面不得复制 Tab 列表或自行绘制底部文字导航。

## 10. 图标与图表

- 使用同一套轮廓图标，默认 2dp 视觉笔画和 24dp 画布。
- 禁止混用 Emoji、填充图标和轮廓图标作为一级功能图标。
- 日历状态同时依赖颜色和形状。
- 图表柱宽、网格线、坐标标签和空数据表现由统一图表主题控制。
- `UNRECORDED` 必须断开折线或留空，不能绘制为零值。

## 11. 动效与触觉

- 按压即时反馈：轻微缩放或颜色变化，释放后提交。
- 默认使用无回弹、临界阻尼的短弹簧；只有拖动排序等带手势速度的动作允许轻微回弹。
- 页面切换目标响应时间约 300ms，简单显隐 150–200ms。
- 所有手势动效必须可中断，不能在动画期间锁定 Tab。
- 打卡成功、排序吸附和真正错误可使用轻触反馈；滚动和普通导航不使用触觉。
- 开启系统“减少动态效果”时改为短淡入淡出。

## 12. 文案与状态反馈

- 使用“未打卡”“今日无烟”“今日吸烟”，不使用模糊的“已完成”。
- 吸烟后的反馈是“已经记录，从现在继续”，不使用失败、破功等词。
- 提醒设置显示下一次实际执行时间，不只显示配置时间。
- 空数据说明原因和下一步，不用空白卡片。
- 危险操作明确写出会删除什么，只在真正不可逆时确认。

## 13. 可访问性

- 所有操作提供语义标签和状态描述。
- 字体放大到 200% 时，主操作仍可见且不重叠。
- 图表提供对应的文字摘要。
- 触控目标不小于 48dp。
- 深色、浅色和高对比场景均需真机检查。

## 14. 桌面组件

桌面组件使用 Glance（Material3）实现，遵循上述设计 Token。

### 尺寸

| 变体 | 网格尺寸 | 布局方向 |
|---|---|---|
| 宽版 | 4×2 | 横向：不抽 → 大天数(40sp) → 小时分钟 → 状态 |
| 紧凑版 | 4×1 | 横向紧凑：不抽 → 天数(20sp) + 时间 → 状态 |
| 竖版 | 2×4 | 竖向居中：不抽 → 大天数(48sp) → 天 → 小时 → 分钟 → 状态 |

### 组件规则

- 背景使用 `surface` 色，圆角 20dp（`radiusCard`）。
- 状态文字使用语义色：`smokeFree`（绿）、`smoked`（红）、`unrecorded`（灰）。
- 深色模式下状态色自动调亮。
- 不显示应用名称标签（Loading 布局为空白背景）。
- 每分钟自动刷新时间。
- 点击组件打开应用"不抽"页（`singleTask` 启动模式，单次返回退出）。
