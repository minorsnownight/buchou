# 产品化重构实施计划

## 总体策略

重构顺序先领域状态，再设计组件，再页面。每个阶段独立构建、测试和真机验收。

## 阶段 0：规格基线 ✅

产物：

- `PRODUCT_SPEC.md`
- `STATE_MODEL.md`
- `DESIGN_SYSTEM.md`
- `IMPLEMENTATION_PLAN.md`

## 阶段 1：领域模型与数据层 ✅

- 连续时长从旅程起点和最新吸烟事件推导。
- 支持同日多条吸烟事件。
- 永久 `AchievementUnlock`。
- 首页模块显示与顺序偏好。
- 累计少抽支数、金额、无烟率、完整度和最长连续时长。
- "重新开始戒烟"和"重置全部数据"的不同语义。
- Room schema 迁移（v1 → v2）。

## 阶段 2：设计系统与导航壳 ✅

- 颜色、排版、间距、圆角和动效 Token。
- `BuchouScaffold` 和唯一 `BuchouTabBar`。
- 设置分组、状态卡片、指标卡片和底部面板组件。
- 三个一级 Tab 使用同一导航状态和返回栈策略。

## 阶段 3："不抽"首页 ✅

- 连续时长、今日状态、核心统计。
- 一键无烟打卡和吸烟记录面板（含烟瘾强度选择）。
- 理由随机展示、健康节点摘要和最近成就。
- 今日允许与禁止的更正路径。

## 阶段 4："记录"页面 ✅

- 月历与日期详情底部面板。
- 7/30/90 天范围选择。
- 支数柱状图、烟瘾趋势、无烟率和完整度。
- 图表文字摘要和空数据状态。

## 阶段 5："设置"页面 ✅

- 设置分组：数据管理、提醒、外观、桌面组件、其他。
- 个人基线编辑。
- 理由管理、首页模块显示和排序。
- WebDAV 同步（支持坚果云）。
- 重新开始戒烟、重置全部数据。
- 外观（主题+首页模块）、语言、货币。

## 阶段 6：提醒与国际化 ✅

- 调度统一使用领域层的最早提醒日期。
- 设置页显示下一次实际执行时间。
- 已打卡后修改设置不重新安排今天。
- 自定义音乐、重启和时区恢复。
- 简体中文 / English 双语支持，切换即生效。

## 阶段 7：Android 桌面组件 ✅

- 三种尺寸：4×2 宽版、4×1 紧凑版、2×4 竖版。
- 横向布局显示"不抽"+ 天数 + 小时分钟 + 今日状态。
- 每分钟自动刷新时间。
- 点击进入应用"不抽"页。
- 数据变化后及时刷新。
- 深浅模式适配。

## 阶段 8：WebDAV 同步 ✅

- 使用 OkHttp 实现 WebDAV 客户端（支持 MKCOL、PUT、GET）。
- 支持坚果云 WebDAV（地址默认 `https://dav.jianguoyun.com/dav/`）。
- 上传：导出事实数据为 JSON，保存到 `buchou/backup.json`。
- 下载：从远端获取备份，覆盖本地事实数据。
- 同步状态显示（上次同步时间、错误信息）。

## 后续计划

- 应急引导（烟瘾发作时的三分钟引导）
- 分享成果海报
- iOS 版本
- 数据合并规则（多设备冲突处理）
